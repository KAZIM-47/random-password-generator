# Random Password Generator

A professional, interactive password generation tool developed using HTML, CSS, and JavaScript. It allows users to generate secure and customizable passwords by selecting the desired password length and character combinations. The application also includes a one-click copy feature and a live password strength indicator for enhanced usability and security awareness.

## Features

- Adjustable password length ranging from **1 to 20 characters**
- Option to include or exclude:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Symbols
- Real-time password strength indicator
- Copy generated password to clipboard with instant tooltip confirmation
- Responsive, clean, and visually polished user interface
- Easy-to-use interactive controls

## Usage

1. Open `rpg.html` in any modern web browser.
2. Use the slider to set the required password length.
3. Select the character types you want to include in the password.
4. Click on **Generate Password** to create a new secure password.
5. Click the **Copy** icon to copy the generated password instantly.

## Technologies Used

- **HTML5** for page structure
- **CSS3** for styling and responsive layout
- **JavaScript** for password generation logic and interactivity

## Project Objective

This project is designed to demonstrate the implementation of random password generation, DOM manipulation, event-driven programming, clipboard handling, and responsive front-end design using core web technologies.
